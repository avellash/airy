# Airy – Aplikasi Pemantauan Kualitas Udara

## Deskripsi Aplikasi

Airy adalah aplikasi pemantauan kualitas udara yang membantu pengguna mengetahui kondisi udara di sekitar berdasarkan lokasi yang dipilih. Aplikasi ini menyediakan informasi Indeks Kualitas Udara (AQI), tingkat kualitas udara, detail polutan seperti PM2.5 dan PM10, serta riwayat pemantauan. Aplikasi ini bertujuan membantu pengguna memahami tingkat pencemaran udara dan lebih peduli terhadap kesehatan.

## Fitur Aplikasi

- **Pemilihan Lokasi:** Memilih lokasi untuk memantau kualitas udara.
- **Kondisi Udara:** Menampilkan kategori kualitas udara.
- **Indeks Kualitas Udara (AQI):** Menampilkan nilai indeks kualitas udara.
- **Detail Polutan:** Menampilkan konsentrasi PM2.5 dan PM10.
- **Pembaruan Data:** Menampilkan waktu pembaruan informasi.
- **Riwayat Pemantauan:** Melihat riwayat kualitas udara.
